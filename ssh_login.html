What happens on login?

Once you log in, you can use the command-line terminal to run Linux commands on your VM. You’ll start in your account’s home directory, where you can create, edit, and delete files. But really, you have access to the full file system. You can perform administrative tasks, such as installing software or configuring settings. You can even integrate your VM with other systems or services.

Step 1. Get Your Key

Create a SSH key, if you haven’t already done so.

  1. Create a file folder
  2. Get the path to this folder
  3. Create a public-private key pair, saving it in this folder.

You should be able to see your keys in your file explorer.

Step 2. Print & Copy Your Public Key

Using the command line, enter ‘cat YOUR_KEY.pub’ but replace YOUR_KEY.pub with the file path and name of your public key.

  1. Open macOS terminal or Microsoft PowerShell.
  2. Type the cat command to print your public key
  3. Copy the printed text to your clipboard.

The cat command:

cat file_path/filename of your public key

The type command:

type file_path/filename of your public key
Notice: At the end of your public key is your username. Look for the username@hostname and remember your username.
3. Navigate to Your Google Cloud Instance

Using your web browser, find your Google Cloud instance.

  1. Open this link to Google Cloud’s welcome page.
  2. In the menu on the left-hand side, select “Compute Engin” and then “VM Instances.”
  3. Find the “name” column and click on the name of your VM.
4. Add Your SSH Key
  1. In the upper left, click the “Edit” button
  2. Scroll down until you find the “SSH Keys” section
  3. Click the “Add item” button
  4. Paste your printed public SSH key into the text input area
  5. Press “Enter” or click the “Save” button located at the bottom of the screen
5. Login with SSH
  1. Go back to the VM Instances page
  2. Start your VM if it is not already running
    1. Click on the check box in the “Status” column for your VM
    2. Click “Start or Resume”
  3. Copy the IP address in the “External IP” column
  4. Open macOS terminal or Windows PowerShell
  5. Run an SSH login command

Remember, the SSH login ends with username@host_ip_address. Your username was at the end of your public key, and your host address is the external IP address.
